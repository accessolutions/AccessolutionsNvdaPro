Accessolutions NVDA Pro

English (US) documentation

Add-on version: 2026.08.26.0001

Accessolutions NVDA Pro adds features to NVDA, including web browsing gestures inspired by JAWS. It also provides incremental search, braille tools, a remote assistance request, and application-specific adaptations

Requirements and compatibility

  • Windows and NVDA are required.
  • The manifest targets NVDA 2026.1.0 or later and declares that version as the last tested version. These values do not guarantee operation on every NVDA release; perform a real-NVDA test before each publication.
  • Remote assistance uses NVDA 2026.1's built-in Remote Access when it is enabled, or a compatible module such as NVDA Remote, Telenvda, or Telenvda Accessolutions when installed and active. If no compatible module is detected, the add-on still attempts to open the connection request.

The add-on uses Python 3 networking APIs. Test it with the exact NVDA version used in production before deploying it to multiple computers.

Installation and preferences

  1. Install the .nvda-addon file through NVDA's Add-ons Manager.
  2. Restart NVDA when prompted.
  3. Open Preferences > Settings > AccessolutionsNVDAPro.

Use JAWS-like gestures in browse mode is enabled by default. When it is enabled, the Accessolutions gesture map is loaded immediately after saving the setting. When it is disabled, NVDA's standard web gestures are used.

Gestures may conflict with NVDA, the browser, or another add-on. The Accessolutions map applies to browse mode and does not replace every NVDA shortcut.

Updates

The add-on automatically checks for new stable versions when NVDA starts. This check can be disabled in Settings with Automatically check for updates when NVDA starts. A manual check is available from the system menu under Accessolutions > Check for updates....

Versions are published in the Accessolutions NVDA Pro public GitHub repository as releases created from tags. Draft and prerelease versions are ignored. The add-on downloads a package only after user confirmation, verifies its SHA-256 hash, and then asks to restart NVDA to complete installation. A network error during startup is logged without interrupting NVDA.

The system menu item Accessolutions > Products and services for people with visual impairments - Accessolutions opens https://accessolutions.fr in the default browser.

Incremental search

Incremental search finds text in a web document without opening a window. It is entirely virtual: text is entered directly from the keyboard and no key is sent to the web page.

  1. Place focus in a web document in browse mode.
  2. Press Ctrl+I.
  3. Type all or part of the text to find, as quickly as needed.
  4. After each character, the add-on searches from the beginning of the document, moves the virtual cursor to the first match, reads its line, and then reads the remaining paragraph when available.

Previous speech is cancelled before the new result is announced. The search stops automatically after four seconds of inactivity. If no characters were entered, NVDA announces that the search was cancelled. If no match is found, NVDA announces that the text was not found.

Input uses NVDA's keyboard conversion so that the active layout is respected, including French keyboard layouts, digits, accented characters, and AltGr. After a successful search, F3 finds the next occurrence and Shift+F3 finds the previous one.

This feature temporarily captures keyboard input. Backspace removes the last character, Escape cancels the search, and Enter completes it. Tab and Shift+Tab complete the search and are then passed to NVDA. The capture is also released automatically after inactivity.

Braille

Win+Ctrl+B switches between the two French braille tables expected by the add-on:

  • uncontracted braille: fr-bfu-comp8.utb;
  • contracted braille: fr-bfu-g2.ctb.

If another table is active, the add-on announces that the braille table is unknown and leaves it unchanged.

The first press enables NVDA's DEBUG logging level. The second press restores the previous level. This level is temporary and is not saved by the add-on; it is also restored when the add-on is disabled.

Debug logs may contain sensitive information, including keyboard input, spoken text, or entered data. Use this mode only for diagnostics and disable it as soon as possible.

Remote assistance

The assistance command opens NVDA Remote in slave mode toward the Accessolutions server and requests the access key supplied by support.

Procedure

  1. Install and enable the NVDA Remote add-on.
  2. Press Win+Ctrl+R, or open the system menu Accessolutions > Remote assistance.
  3. In the dialog, enter the access key supplied by Accessolutions support. Choose OK to launch NVDA Remote, or choose Cancel to abort.

Before requesting a new connection, the add-on checks that remote access is enabled and inspects the known remote modules. If a remote session is already active, the add-on asks for confirmation and disconnects it before starting the new slave connection. If the user declines, the disconnection fails, or a connection is still reported as active, the new request is not started. If the module cannot confirm its state after the disconnection request, the attempt is still made and the remote module handles the situation. If no compatible remote module is detected, the URL is also opened; its handling then depends on whether a nvdaremote:// protocol handler is present on the computer.

The add-on does not store the key. To end an established session, use the disconnect command provided by the remote module.

Privacy and security: the add-on passes the entered key only to NVDA Remote's nvdaremote:// protocol handler. The key is not stored by the add-on. Share it only with Accessolutions support, and check your organization's security policy before using this feature on a sensitive computer.

Application-specific behavior

Windows Notepad

In Notepad, Ctrl+Shift+R toggles announcements of braille routing cursor numbers. When enabled, activating a routing cursor speaks its number; when disabled, the braille gesture is passed to its normal handler.

OpenBook

When the OpenBook window receives focus, NVDA speech is cancelled and the speech mode is turned off. When OpenBook loses focus, the speech mode that was active before entering the application is restored. This preserves the user's speech setting after using OpenBook.

Firefox and WebAccess

The add-on no longer modifies Firefox's Gecko virtual buffer. The Elements List and its behavior in focus mode are handled by NVDA itself, avoiding a global replacement of an internal method and reducing the risk of regressions after updates.

NVDA installation

Win+Ctrl+I opens NVDA's official installer. This gesture does not install the Accessolutions NVDA Pro add-on itself. Use NVDA's Add-ons Manager to install the add-on.

Troubleshooting

  • The Accessolutions menu is missing: check that the add-on is enabled and restart NVDA.
  • Web gestures do not work: check the AccessolutionsNVDAPro setting and use the gestures in a document in browse mode.
  • A gesture conflicts with another command: disable the JAWS-like gestures in Settings, restart NVDA, and use NVDA's standard gestures.
  • Remote assistance fails: check that NVDA's built-in Remote Access is enabled or that a compatible module is installed and active, that the network allows the connection, and that the Accessolutions server is available. An existing remote session must be confirmed and disconnected before a new request.
  • The keyboard appears captured after Ctrl+I: wait for the timeout, press Escape to cancel the search, or restart NVDA as a last resort. Then inspect the NVDA log for an incremental-search error.

Known limitations and technical review

The following points remain relevant:

  • the update system depends on the configured public GitHub repository existing and publishing valid releases;
  • automatic updates are never silent: user confirmation and an NVDA restart are required;
  • incremental search still relies on private NVDA attributes and should be tested against the targeted NVDA releases;
  • compatibility of the Elements List with older NVDA versions still needs testing if those versions remain supported;
  • the update mechanism verifies the published SHA-256 hash, but this does not replace cryptographic package signing; redirects are limited to approved GitHub domains;
  • in-flight network requests are cancelled when the add-on stops, but real-NVDA testing is still required to confirm every feature.

When reporting a problem, reproduce it with other add-ons disabled when possible and attach the NVDA log. Never publish a remote-assistance session URL or personal information in a public report.
