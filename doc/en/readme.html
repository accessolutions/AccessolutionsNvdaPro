Accessolutions NVDA Pro

English (US) documentation

Add-on version: 2026.08.25.0001

Accessolutions NVDA Pro adds features to NVDA, including web browsing gestures inspired by JAWS. It also provides incremental search, braille tools, a remote assistance request, and application-specific adaptations for Windows software.

Requirements and compatibility

  • Windows and NVDA are required.
  • The manifest declares a minimum NVDA version of 2018.2.1 and a last tested version of 2026.4.0. These values are declarations and do not guarantee operation on every NVDA release.
  • Remote assistance requires the NVDA Remote add-on to be installed and enabled in NVDA.

Some code uses legacy NVDA APIs and Python 2-specific calls. Test the add-on with the exact NVDA version used in production before deploying it to multiple computers.

Installation and preferences

  1. Install the .nvda-addon file through NVDA's Add-ons Manager.
  2. Restart NVDA when prompted.
  3. Open Preferences > Settings > AccessolutionsNVDAPro.

Use JAWS-like gestures in browse mode is enabled by default. When it is disabled, NVDA's standard web gestures are used after NVDA is restarted. When it is enabled, the Accessolutions gesture map is loaded immediately after saving the setting.

Gestures may conflict with NVDA, the browser, or another add-on. The Accessolutions map applies to browse mode and does not replace every NVDA shortcut.

Updates

The add-on automatically checks for new stable versions when NVDA starts. This check can be disabled in Settings with Automatically check for updates when NVDA starts. A manual check is available from the system menu under Accessolutions > Check for updates....

Versions are published in the Accessolutions NVDA Pro public GitHub repository as releases created from tags. Draft and prerelease versions are ignored. The add-on downloads a package only after user confirmation, verifies its SHA-256 hash, and then asks to restart NVDA to complete installation. A network error during startup is logged without interrupting NVDA.

Incremental search

Incremental search finds text in a web document without opening the usual search dialog.

  1. Place focus in a web document in browse mode.
  2. Press Ctrl+I.
  3. Type all or part of the text to find.
  4. After a short pause, the add-on searches from the beginning of the document, selects the first match, and reads its line.

The search stops automatically after a period of inactivity. If no characters were entered, NVDA announces that the search was cancelled. If no match is found, NVDA announces that the text could not be found.

This feature temporarily captures keyboard input. Tab, Shift+Tab, Escape, and Enter are not handled reliably by the current implementation. Use this command only in a web document and restart NVDA if keyboard capture appears to remain active.

Braille

Win+Ctrl+B switches between the two French braille tables expected by the add-on:

  • uncontracted braille: fr-bfu-comp8.utb;
  • contracted braille: fr-bfu-g2.ctb.

If another table is active, the add-on announces that the braille table is unknown and leaves it unchanged.

Remote assistance

The assistance command connects NVDA Remote as a slave to the Accessolutions server and sends connection information to the assistance service.

Procedure

  1. Install and enable the NVDA Remote add-on.
  2. Press Win+Ctrl+R, or open the system menu Accessolutions > Remote assistance.
  3. Confirm the connection request.
  4. A session key is generated. The connection URL is copied to the clipboard and sent to the Accessolutions service together with the current Windows account name.
  5. To end an existing session, use the same shortcut and confirm disconnection.

If NVDA Remote is not installed or is not loaded, the add-on announces that the module cannot be found.

Privacy and security: the current code uses port 80 for the NVDA Remote connection, and the assistance request URL uses HTTP. The session URL and Windows user name are therefore sent to an external service without visible HTTPS protection in this code. Check your organization's security policy before using this feature on a sensitive computer.

Application-specific behavior

Windows Notepad

In Notepad, Ctrl+Shift+R toggles announcements of braille routing cursor numbers. When enabled, activating a routing cursor speaks its number; when disabled, the braille gesture is passed to its normal handler.

OpenBook

When the OpenBook window receives focus, NVDA speech is cancelled and the speech mode is turned off. When OpenBook loses focus, the speech mode is set back to "talk" mode. This can override the speech behavior expected by the user while OpenBook is active.

Firefox and WebAccess

The add-on applies an internal patch to Firefox's Gecko virtual buffer to improve accessible-object membership checks. This workaround depends on private NVDA and Firefox APIs and may become incompatible after an update.

NVDA installation

Win+Ctrl+I opens an old NVDA installation interface contained in the module. This gesture does not install the Accessolutions NVDA Pro add-on itself. Use NVDA's Add-ons Manager to install the add-on.

Troubleshooting

  • The Accessolutions menu is missing: check that the add-on is enabled and restart NVDA.
  • Web gestures do not work: check the AccessolutionsNVDAPro setting and use the gestures in a document in browse mode.
  • A gesture conflicts with another command: disable the JAWS-like gestures in Settings, restart NVDA, and use NVDA's standard gestures.
  • Remote assistance fails: check that NVDA Remote is installed, that the network allows the connection, and that the Accessolutions server is available.
  • The keyboard appears captured after Ctrl+I: wait for the timeout or restart NVDA, then inspect the NVDA log for an incremental-search error.

Known limitations and technical review

The following points were found in the documented version:

  • the update system depends on the configured public GitHub repository existing and publishing valid releases;
  • automatic updates are never silent: user confirmation and an NVDA restart are required;
  • urllib.FancyURLopener, urllib.urlretrieve, and unicode are Python 2-era calls and may fail with Python 3;
  • incremental search relies on private NVDA attributes and contains processing branches after a return statement, making those branches unreachable;
  • the Firefox workaround directly replaces an internal NVDA method;
  • the update mechanism contains no signature or checksum verification in this code;
  • cleanup and error handling should be tested against current NVDA releases.

When reporting a problem, reproduce it with other add-ons disabled when possible and attach the NVDA log. Never publish a remote-assistance session URL or personal information in a public report.
