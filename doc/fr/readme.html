Accessolutions NVDA Pro

Documentation française

Version de l'extension : 2026.08.26.0001

Accessolutions NVDA Pro ajoute des fonctions à NVDA et propose notamment des raccourcis de navigation web inspirés de JAWS. L'extension fournit également une recherche incrémentale, des outils liés au braille, une demande d'assistance à distance et quelques adaptations à des applications Windows.

Prérequis et compatibilité

  • Windows et NVDA sont nécessaires.
  • Le manifeste cible NVDA 2026.1.0 au minimum et déclare cette version comme dernière version testée. Ces valeurs ne constituent pas une garantie de fonctionnement sur toutes les versions ; un test réel doit être effectué avant chaque publication.
  • L'assistance à distance utilise l'accès distant intégré de NVDA s'il est activé dans NVDA 2026.1, ou un module compatible comme NVDA Remote, Telenvda ou Telenvda Accessolutions s'il est installé et actif. Si aucun module compatible n'est détecté, l'extension tente tout de même d'ouvrir la demande de connexion.

Le code de l'extension utilise les API réseau de Python 3. La compatibilité reste à valider avec la version exacte de NVDA utilisée avant un déploiement auprès de plusieurs postes.

Installation et préférences

  1. Installez le fichier .nvda-addon avec le gestionnaire des extensions de NVDA.
  2. Redémarrez NVDA lorsque cela est demandé.
  3. Ouvrez Préférences > Paramètres > AccessolutionsNVDAPro.

La case En mode navigation, utiliser des raccourcis similaires à JAWS est cochée par défaut. Si elle est cochée, la carte de raccourcis Accessolutions est chargée immédiatement après l'enregistrement. Si elle est décochée, les raccourcis de navigation web standards de NVDA sont utilisés.

Les raccourcis peuvent entrer en conflit avec ceux de NVDA, du navigateur ou d'une autre extension. La carte Accessolutions ne concerne que le mode navigation ; elle ne remplace pas tous les raccourcis de NVDA.

Mises à jour

L'extension recherche automatiquement les nouvelles versions stables au démarrage de NVDA. Cette recherche peut être désactivée dans les préférences avec la case Rechercher automatiquement les mises à jour au démarrage de NVDA. Une vérification manuelle est disponible dans le menu système Accessolutions > Vérifier les mises à jour....

Les versions sont publiées dans le dépôt public GitHub d'Accessolutions NVDA Pro sous forme de releases créées à partir de tags. L'extension ignore les brouillons et les versions de prépublication. Elle télécharge le paquet uniquement après confirmation de l'utilisateur, vérifie son empreinte SHA-256, puis demande le redémarrage de NVDA pour terminer l'installation. Une erreur réseau au démarrage est enregistrée dans le journal sans interrompre NVDA.

Le menu système Accessolutions > Produits et services pour personnes déficientes visuelles - Accessolutions ouvre le site https://accessolutions.fr dans le navigateur par défaut.

Recherche incrémentale

La recherche incrémentale permet de rechercher du texte dans un document web sans ouvrir de fenêtre. Elle est entièrement virtuelle : le texte est saisi directement au clavier et aucune touche n'est envoyée à la page web.

  1. Placez le focus dans un document web en mode navigation.
  2. Appuyez sur Ctrl+I.
  3. Tapez tout ou partie du texte recherché, rapidement si nécessaire.
  4. À chaque caractère, l'extension recherche depuis le début du document, déplace le curseur virtuel sur la première occurrence et lit sa ligne, puis la suite du paragraphe lorsqu'elle est disponible.

La parole précédente est interrompue avant l'annonce du nouveau résultat. La recherche s'arrête automatiquement après quatre secondes d'inactivité. Si aucun caractère n'a été saisi, NVDA annonce « Recherche annulée ». Si le texte n'est pas trouvé, NVDA l'annonce comme introuvable.

La saisie utilise la conversion clavier de NVDA afin de respecter la disposition active, notamment pour les claviers français, les chiffres, les caractères accentués et AltGr. Après une recherche réussie, F3 recherche l'occurrence suivante et Maj+F3 l'occurrence précédente.

Cette fonction capture temporairement les frappes clavier. Retour arrière supprime le dernier caractère, Échap annule la recherche, et Entrée la termine. Les touches Tab et Maj+Tab terminent la recherche puis sont transmises à NVDA. La capture est également libérée automatiquement après l'inactivité.

Braille

Win+Ctrl+B bascule entre les deux tables braille françaises attendues par l'extension :

  • braille intégral : fr-bfu-comp8.utb ;
  • braille abrégé : fr-bfu-g2.ctb.

Si une autre table est active, l'extension annonce que la table braille est inconnue et ne la modifie pas.

Le premier appui active le niveau de journalisation DEBUG de NVDA. Le second appui restaure le niveau précédent. Le niveau est temporaire et n'est pas enregistré par l'extension ; il est également restauré lorsque l'extension est désactivée.

Les journaux de débogage peuvent contenir des informations sensibles, notamment des frappes clavier, du texte lu ou des données saisies. Ce mode doit être utilisé uniquement pour le diagnostic et désactivé dès que possible.

Assistance à distance

La commande d'assistance ouvre NVDA Remote en mode esclave vers le serveur Accessolutions et demande la clé d'accès fournie par le support.

Procédure

  1. Installez et activez l'extension NVDA Remote.
  2. Appuyez sur Win+Ctrl+R, ou ouvrez le menu système Accessolutions > Assistance à distance.
  3. Dans la boîte de dialogue, saisissez la clé d'accès fournie par le support Accessolutions. Validez avec OK pour lancer NVDA Remote, ou choisissez Annuler pour abandonner.

Avant de demander la nouvelle connexion, l'extension vérifie l'accès distant activé et l'état des modules connus. Si une connexion distante est déjà active, une confirmation est demandée ; elle est déconnectée avant le lancement de la nouvelle connexion esclave. En cas de refus, d'échec de déconnexion ou si une connexion est encore signalée comme active, la nouvelle demande n'est pas lancée. Si le module ne permet pas de confirmer l'état après la demande de déconnexion, l'essai est tout de même effectué et le module distant gère alors la situation. Si aucun module distant compatible n'est détecté, l'URL est également ouverte ; son traitement dépend alors de la présence d'un gestionnaire du protocole nvdaremote:// sur le poste.

La clé n'est pas enregistrée par l'extension. Pour interrompre une session établie, utilisez ensuite la commande de déconnexion proposée par le module distant.

Confidentialité et sécurité : l'extension transmet la clé saisie uniquement au gestionnaire du protocole nvdaremote:// de NVDA Remote. La clé n'est pas enregistrée par l'extension. Ne communiquez la clé qu'au support Accessolutions et vérifiez la politique de sécurité de votre organisation avant d'utiliser cette fonction sur un poste sensible.

Adaptations par application

Bloc-notes Windows

Dans le Bloc-notes, Ctrl+Maj+R active ou désactive l'annonce du numéro des curseurs de routage braille. Lorsque l'option est active, l'activation d'un curseur de routage annonce son numéro ; lorsqu'elle est inactive, le geste braille est transmis à son traitement habituel.

OpenBook

Lorsque la fenêtre OpenBook reçoit le focus, la parole de NVDA est annulée et le mode de parole est désactivé. Lorsque OpenBook perd le focus, le mode de parole utilisé avant l'entrée dans l'application est restauré. Le réglage de parole de l'utilisateur est ainsi conservé après l'utilisation d'OpenBook.

Firefox et WebAccess

L'extension ne modifie plus le tampon virtuel Gecko de Firefox. La liste des éléments et son fonctionnement en mode formulaire sont laissés au traitement standard de NVDA, ce qui évite de remplacer une méthode interne globale et réduit les risques après une mise à jour.

Installation de NVDA

Win+Ctrl+I ouvre l'installateur officiel de NVDA lui-même. Ce raccourci n'installe pas l'extension Accessolutions NVDA Pro. Pour installer l'extension, utilisez le gestionnaire des extensions de NVDA.

Dépannage

  • Le menu Accessolutions est absent : vérifiez que l'extension est activée, puis redémarrez NVDA.
  • Les raccourcis web ne répondent pas : vérifiez la case AccessolutionsNVDAPro dans les paramètres de NVDA et utilisez les raccourcis dans un document en mode navigation.
  • Un raccourci est en conflit : désactivez les gestes français dans les paramètres, redémarrez NVDA et utilisez les gestes standards de NVDA.
  • L'assistance échoue : vérifiez que l'accès distant intégré de NVDA est activé ou qu'un module compatible est installé et actif, que le réseau autorise la connexion et que le serveur Accessolutions est disponible. Une session distante existante doit être confirmée puis déconnectée avant une nouvelle demande.
  • Le clavier semble capturé après Ctrl+I : attendez la fin du délai, appuyez sur Échap pour annuler la recherche ou redémarrez NVDA en dernier recours. Consultez ensuite le journal NVDA si une erreur liée à la recherche incrémentale est enregistrée.

Limites et revue technique

Les points suivants restent à prendre en compte :

  • le système de mise à jour dépend de l'existence et de la publication correcte du dépôt GitHub public configuré dans le module ;
  • les mises à jour automatiques ne sont jamais silencieuses : une confirmation et un redémarrage de NVDA sont demandés ;
  • la recherche incrémentale s'appuie toujours sur des attributs privés de NVDA et doit être testée sur les versions ciblées ;
  • la compatibilité de la liste des éléments avec les anciennes versions de NVDA doit encore être testée si ces versions sont conservées ;
  • le mécanisme de mise à jour vérifie l'empreinte SHA-256 publiée, mais ne remplace pas une signature cryptographique du paquet ; les redirections sont limitées aux domaines GitHub autorisés ;
  • les requêtes réseau en cours sont annulées lors de l'arrêt de l'extension, mais le test avec NVDA réel reste nécessaire pour confirmer le comportement de toutes les fonctions.

En cas de problème, reproduisez-le avec les autres extensions désactivées lorsque cela est possible, puis joignez le journal NVDA à votre rapport. Ne transmettez jamais une URL de session d'assistance ou une information personnelle dans un rapport public.
