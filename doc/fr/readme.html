Accessolutions NVDA Pro

Documentation française

Version de l'extension : 2026.08.25.0001

Accessolutions NVDA Pro ajoute des fonctions à NVDA et propose notamment des raccourcis de navigation web inspirés de JAWS. L'extension fournit également une recherche incrémentale, des outils liés au braille, une demande d'assistance à distance et quelques adaptations à des applications Windows.

Prérequis et compatibilité

  • Windows et NVDA sont nécessaires.
  • Le manifeste déclare une version minimale de NVDA 2018.2.1 et une dernière version testée 2026.4.0. Ces valeurs sont déclaratives et ne constituent pas une garantie de fonctionnement sur toutes les versions.
  • L'assistance à distance nécessite l'extension NVDA Remote, installée et activée dans NVDA.

Une partie du code utilise des API anciennes de NVDA et des appels propres à Python 2. Il est donc recommandé de valider l'extension avec la version exacte de NVDA utilisée avant un déploiement auprès de plusieurs postes.

Installation et préférences

  1. Installez le fichier .nvda-addon avec le gestionnaire des extensions de NVDA.
  2. Redémarrez NVDA lorsque cela est demandé.
  3. Ouvrez Préférences > Paramètres > AccessolutionsNVDAPro.

La case En mode navigation, utiliser des raccourcis similaires à JAWS est cochée par défaut. Si elle est décochée, les raccourcis de navigation web standards de NVDA sont utilisés après redémarrage de NVDA. Si elle est cochée, la carte de raccourcis Accessolutions est chargée immédiatement après l'enregistrement.

Les raccourcis peuvent entrer en conflit avec ceux de NVDA, du navigateur ou d'une autre extension. La carte Accessolutions ne concerne que le mode navigation ; elle ne remplace pas tous les raccourcis de NVDA.

Mises à jour

L'extension recherche automatiquement les nouvelles versions stables au démarrage de NVDA. Cette recherche peut être désactivée dans les préférences avec la case Rechercher automatiquement les mises à jour au démarrage de NVDA. Une vérification manuelle est disponible dans le menu système Accessolutions > Vérifier les mises à jour....

Les versions sont publiées dans le dépôt public GitHub d'Accessolutions NVDA Pro sous forme de releases créées à partir de tags. L'extension ignore les brouillons et les versions de prépublication. Elle télécharge le paquet uniquement après confirmation de l'utilisateur, vérifie son empreinte SHA-256, puis demande le redémarrage de NVDA pour terminer l'installation. Une erreur réseau au démarrage est enregistrée dans le journal sans interrompre NVDA.

Recherche incrémentale

La recherche incrémentale permet de rechercher du texte dans un document web sans ouvrir la boîte de dialogue de recherche classique.

  1. Placez le focus dans un document web en mode navigation.
  2. Appuyez sur Ctrl+I.
  3. Tapez tout ou partie du texte recherché.
  4. Après une courte pause, l'extension recherche la première occurrence à partir du début du document, sélectionne la ligne trouvée et la lit.

La recherche s'arrête automatiquement après une période d'inactivité. Si aucun caractère n'a été saisi, NVDA annonce « Recherche annulée ». Si le texte n'est pas trouvé, NVDA annonce qu'il est introuvable.

Cette fonction capture temporairement les frappes clavier. Les touches Tab, Maj+Tab, Échap et Entrée ne sont pas gérées de manière fiable par la version actuelle ; utilisez cette commande uniquement dans un document web et redémarrez NVDA si la capture clavier semble rester active.

Braille

Win+Ctrl+B bascule entre les deux tables braille françaises attendues par l'extension :

  • braille intégral : fr-bfu-comp8.utb ;
  • braille abrégé : fr-bfu-g2.ctb.

Si une autre table est active, l'extension annonce que la table braille est inconnue et ne la modifie pas.

Assistance à distance

La commande d'assistance connecte NVDA Remote comme esclave au serveur Accessolutions et transmet les informations de connexion au service d'assistance.

Procédure

  1. Installez et activez l'extension NVDA Remote.
  2. Appuyez sur Win+Ctrl+R, ou ouvrez le menu système Accessolutions > Assistance à distance.
  3. Confirmez la connexion à l'assistance.
  4. Une clé de session est générée. L'URL de connexion est copiée dans le presse-papiers et envoyée au service Accessolutions avec le nom du compte Windows courant.
  5. Pour interrompre une session existante, réutilisez le même raccourci et confirmez la déconnexion.

Si NVDA Remote n'est pas installé ou n'est pas chargé, l'extension annonce que le module est introuvable.

Confidentialité et sécurité : le code actuel utilise le port 80 pour la connexion NVDA Remote et l'URL de demande d'assistance est en HTTP. L'URL de session et le nom d'utilisateur Windows sont donc transmis à un service externe sans protection HTTPS visible dans ce code. Vérifiez la politique de sécurité de votre organisation avant d'utiliser cette fonction sur un poste sensible.

Adaptations par application

Bloc-notes Windows

Dans le Bloc-notes, Ctrl+Maj+R active ou désactive l'annonce du numéro des curseurs de routage braille. Lorsque l'option est active, l'activation d'un curseur de routage annonce son numéro ; lorsqu'elle est inactive, le geste braille est transmis à son traitement habituel.

OpenBook

Lorsque la fenêtre OpenBook reçoit le focus, la parole de NVDA est annulée et le mode de parole est désactivé. Lorsque OpenBook perd le focus, le mode de parole est remis en mode « talk ». Ce comportement peut modifier un réglage de parole attendu par l'utilisateur pendant l'utilisation d'OpenBook.

Firefox et WebAccess

L'extension applique un correctif interne au tampon virtuel Gecko de Firefox afin d'améliorer le test d'appartenance des objets accessibles. Il s'agit d'un contournement dépendant des API internes de NVDA et de Firefox ; il peut devenir incompatible après une mise à jour.

Installation de NVDA

Win+Ctrl+I ouvre une ancienne interface d'installation de NVDA présente dans le code du module. Ce raccourci ne correspond pas à l'installation de l'extension Accessolutions NVDA Pro elle-même. Pour installer l'extension, utilisez le gestionnaire des extensions de NVDA.

Dépannage

  • Le menu Accessolutions est absent : vérifiez que l'extension est activée, puis redémarrez NVDA.
  • Les raccourcis web ne répondent pas : vérifiez la case AccessolutionsNVDAPro dans les paramètres de NVDA et utilisez les raccourcis dans un document en mode navigation.
  • Un raccourci est en conflit : désactivez les gestes français dans les paramètres, redémarrez NVDA et utilisez les gestes standards de NVDA.
  • L'assistance échoue : vérifiez que NVDA Remote est installé, que le réseau autorise la connexion et que le serveur Accessolutions est disponible.
  • Le clavier semble capturé après Ctrl+I : attendez la fin du délai ou redémarrez NVDA, puis consultez le journal NVDA pour rechercher une erreur liée à la recherche incrémentale.

Limites et revue technique

Les points suivants ont été constatés dans la version documentée :

  • le système de mise à jour dépend de l'existence et de la publication correcte du dépôt GitHub public configuré dans le module ;
  • les mises à jour automatiques ne sont jamais silencieuses : une confirmation et un redémarrage de NVDA sont demandés ;
  • les appels urllib.FancyURLopener, urllib.urlretrieve et unicode sont hérités de Python 2 et peuvent échouer avec Python 3 ;
  • la recherche incrémentale s'appuie sur des attributs privés de NVDA et contient des branches de traitement placées après un retour, donc inatteignables ;
  • le correctif Firefox modifie directement une méthode interne de NVDA ;
  • le mécanisme de mise à jour ne présente pas de vérification de signature ou d'empreinte dans ce code ;
  • les fonctions de nettoyage et la gestion des erreurs mériteraient des tests sur les versions modernes de NVDA.

En cas de problème, reproduisez-le avec les autres extensions désactivées lorsque cela est possible, puis joignez le journal NVDA à votre rapport. Ne transmettez jamais une URL de session d'assistance ou une information personnelle dans un rapport public.
