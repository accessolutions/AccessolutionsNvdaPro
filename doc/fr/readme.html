Ce module apporte des fonctionnalités et des améliorations au lecteur d'écran NVDA, rendant son utilisation plus confortable tout en facilitant la transition depuis d'autres lecteurs d'écran.

Affichage braille

  • Des améliorations ont été apportées au niveau de l'affichage - des informations délivrées par les afficheurs braille compatibles afin de se rapprocher du mode dit structuré que l'on peut trouver dans d'autres lecteurs d'écran. Par défaut, NVDA affiche en braille un grand nombre d'informations telles que le titre de la fenêtre, le contenu de la boîte de dialogue, le nom de l'objet et son type. Le module s'efforce donc de n'afficher que l'information située sous le curseur et prononcée par la synthèse vocale, privilégiant ainsi la pertinence par rapport à la quantité. Il est toujours possible si nécessaire d'utiliser les touches de défilement avant et arrière de l'afficheur pour prendre connaissance des autres informations.
  • Il est possible de basculer entre le braille intégral et le braille abrégé en utilisant la combinaison de touches Win+Ctrl+B.

Microsoft Outlook

  • La gestion de pièces jointes dans les messages reçus a été améliorée. Les images présentes dans un courrier électronique, comme par exemple celles insérées dans une signature, ne sont plus traitées comme des pièces jointes, évitant ainsi les annonces de fichiers joints alors qu'il n'y en a pas.
  • Dans la liste des messages, le noms des en-têtes de colonnes telles que objet, expéditeur ou encore destinataire ne sont plus prononcées. Seul leur contenu est vocalisé, ce qui rend la lecture nettement plus fluide.

OpenBook

Le module améliore le fonctionnement du logiciel de reconnaissance de caractères OpenBook quand NVDA est en cours d'utilisation. Lorsque le focus se trouve sur la fenêtre d'openBook, le synthétiseur vocal de NVDA est automatiquement mis en veille pour basculer sur celui d'OpenBook, permettant ainsi une utilisation transparente des commandes de ce dernier, tout en bénéficiant du suivi braille de NVDA le cas échéant. NVDA reprendra la main lors de la fermeture d'OpenBook ou si le focus ne se trouve plus sur la fenêtre de ce dernier.

Mode navigation

Des ajustements ont été apportés aux raccourcis clavier disponibles en mode navigation pour plus de cohérence avec la langue française et les autres lecteurs d'écran pour Windows. Ce mode est principalement actif au sein d'un navigateur internet ou tout autre fenêtre de type web. voici la liste des raccourcis clavier modifiés :

Nom Touche Description
Rechercher Ctrl+F Affiche un dialogue qui vous permet de rechercher du texte dans le document courant
Rechercher suivant f3 Recherche l'occurrence suivante du texte préalablement recherché dans le document
Rechercher précédent maj+f3 Recherche l'occurrence précédente du texte préalablement recherché dans le document
Réactualiser le document NVDA+Echap Recharge le document en cours, (utile si le contenu de la page semble incomplet.
Aller au début du conteneur Maj+Q Se déplace au début du conteneur (liste, tableau etc.) où le curseur est positionné
Aller après la fin du conteneur Q Se déplace après la fin du conteneur (liste, tableau etc.) où le curseur se trouve

les raccourcis de navigation rapide, ces raccourcis à touche unique permettant d'atteindre un champ donné au sein d'un document pris en charge ont également été modifiés. Les touches suivantes permettent d'aller à l'élément suivant. En les combinant avec maj, on retourne à l'élément précédent.

  • t : titre
  • y : tableau
  • n : lien non visité
  • u : bouton
  • z : liste déroulante
  • c : balise de citation
  • h : cadre

Correction diverses

  • La fonction appelée par le raccourci NVDA+F7 et permettant d'afficher la liste des éléments d'une page web a été modifié afin de fonctionner même lorsque le mode formulaire est activé.
  • Pour les utilisateurs avancés développant des scripts, un mode Debug a été ajouté afin d'aider les développeurs à tester leurs scripts grâce à l'émission de sinaux sonores en cas d'erreurs dans le code. Pour passer du mode Debug au mode normal, utiliser la combinaison de touches Ctrl+Windows+D.
