Cette extension apporte des fonctionnalités et des améliorations au lecteur d'écran NVDA, qui visent pincipalement à faciliter la transition depuis le lecteur d'écran JAWS, particulièrement en mode navigation web.

Mode navigation

Des ajustements ont été apportés aux raccourcis clavier disponibles en mode navigation pour plus de cohérence avec la langue française et le lecteur d'écran JAWS. Ce mode est principalement actif au sein d'un navigateur internet ou tout autre fenêtre de type web. voici la liste des raccourcis clavier modifiés. Veuillez noter que l'on peut revenir aux raccourcis web par défaut de NVDA en décochant la case idoine dans la rubrique "AccessolutionsNVDAPro" des préférences de NVDA:

  • Rechercher, Ctrl+F : Affiche un dialogue qui vous permet de rechercher du texte dans le document courant
  • Rechercher suivant, F3 : Recherche l'occurrence suivante du texte préalablement recherché dans le document
  • Rechercher précédent, Maj+f3 : Recherche l'occurrence précédente du texte préalablement recherché dans le document
  • Réactualiser le document, NVDA+Echap : Recharge le document en cours, (utile si le contenu de la page semble incomplet.
  • Aller au début du conteneur, Maj+Q : Se déplace au début du conteneur (liste, tableau etc.) où le curseur est positionné
  • Aller après la fin du conteneur, Q : Se déplace après la fin du conteneur (liste, tableau etc.) où le curseur est positionné.

Recherche incrémentale

La "Recherche incrémentale" est une fonctionnalité pratique de l'extension AccessolutionsNVDAPro, qui permet de rechercher une châine de caractères dans un contenu web, plus rapidement qu'avec la boîte de dialogue de recherche classique. Supposons que vous voulez trouver un lien de contact sur une page web. Il vous suffit simplement de faire le raccourci clavier Ctrl+i, de taper tout ou partie du mot "contact", et le curseur sera automatiquement placé sur la première occurrence contenant la chaîne de caractères saisie.

Affichage braille

  • Il est possible de basculer entre le braille intégral et le braille abrégé en utilisant la combinaison de touches Win+Ctrl+B.
